# 공역 데이터 연결 원칙

DRONE LAB의 공역 레이어는 실제 비행 허가 판정기가 아니라 최신 정보를 확인하도록 돕는 참고 UI입니다. 현재 홍제천은 공식 공역 데이터가 연결되지 않은 `unavailable` 상태이며, 지도에 규제 구역을 추정해 표시하지 않습니다.

## 데이터 계약

지역 로더는 선택적으로 `AreaAirspaceData`를 반환합니다.

- `status`: `unavailable` 또는 `advisory`
- `capturedAt`: 원본을 확인한 ISO 시각
- `sourceUrl`: 사용자가 원문을 다시 확인할 수 있는 공식 URL
- `zones`: 로컬 좌표 다각형, 구역 종류, 고도 범위와 설명

`advisory`로 전환하려면 출처의 재사용 조건, 좌표계, 고도 기준(AGL/MSL), 데이터 갱신 주기와 임시 제한의 만료 처리를 먼저 확정해야 합니다. 오래된 캐시를 최신 규제로 오인하지 않도록 수집 시각과 출처를 UI에 항상 표시합니다.

## 안전 원칙

- 데이터가 없거나 검증에 실패하면 구역을 추정하지 않고 `unavailable`로 되돌립니다.
- 시뮬레이션의 100 m 제한과 지역 경계를 법적 제한처럼 표현하지 않습니다.
- 참고 레이어가 있더라도 실제 비행 전 공식 채널, 관할 기관 승인, 기상과 현장 조건을 다시 확인해야 합니다.
- 항공안전법 해석이나 비행 승인 자동화를 이 데이터만으로 수행하지 않습니다.
