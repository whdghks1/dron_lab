# Poly Haven CC0 material maps

이 폴더에는 홍제천 근거리 재질에 필요한 파일만 포함합니다.

- `concrete-*`: Poly Haven Concrete, Rob Tuytel, CC0 1.0
- `stone-wall-05-*`: Poly Haven Stone Wall 05, Charlotte Baglioni, CC0 1.0
- `*-diff-1k.jpg`: 1024×1024 sRGB diffuse
- `*-normal-gl-512.jpg`: 512×512 OpenGL normal
- `*-rough-512.jpg`: 512×512 roughness

원본 URL, 원본 MD5, 다운로드 날짜와 재인코딩 설정은 저장소 루트의 `THIRD_PARTY_ASSETS.md`를 참고합니다. 이 파일들은 실제 홍제천 표면 촬영본이 아닙니다.
